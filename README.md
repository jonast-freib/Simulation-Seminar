# SPH Fluid Solver

A 2D smoothed-particle hydrodynamics (SPH) simulation written in C++17. The application uses SFML for rendering and exposes several solver parameters as interactive controls while the simulation is running.

## Features
- 2D particle simulation with density, pressure, viscosity, and gravity forces.
- Radius-based neighbor search for local particle interactions.
- Fixed particles for simple container boundaries.
- Runtime controls for solver parameters.
- A reset action that restores the active scene to its initial positions.
- A standalone neighbor-search test executable registered with CTest.

## Requirements
- CMake 3.10 or newer.
- A C++17 compiler.
- SFML 3 with the Graphics component available to CMake.
- A desktop environment capable of opening an SFML window.

## Build and run
From the repository root:

```sh
cmake -S . -B build
cmake --build build
./build/sph_solver
```

The exact executable location can vary by generator. Use `cmake --build build --target sph_solver` to rebuild only the application.

## Tests
```sh
ctest --test-dir build --output-on-failure
```

## Reproducing the report's data and figures
```sh
./build/sph_experiments data      # writes the CSV data to data/ (about 75 s on 12 cores)
python3 plots/make_plots.py       # reads data/, writes figures/ (needs matplotlib and numpy)
```

`data/martin_moyce_n2.csv` is shipped with the code: it holds the experimental dam-break
front of Martin & Moyce (1952) for n^2 = 2, which `make_plots.py` adds to `figures/dam_front.pdf`.
All other CSV files are generated by `sph_experiments`.

## Project layout
| Path | Responsibility |
| --- | --- |
| `src/main.cpp` | Application setup, presets, event loop, and simulation stepping |
| `src/SPHSolver.cpp` | SPH density, pressure, force, and integration calculations |
| `src/NeighborSearch.cpp` | Neighbor list construction |
| `src/Scenes.cpp` | Test scenes (dam break, hydrostatic column) and their parameters |
| `tools/experiments.cpp` | Headless experiment runner that writes the paper's CSV data |
| `src/Renderer.cpp` | SFML window, particle drawing, sliders, and buttons |
| `include/` | Public headers for the simulation components |
| `tests/` | Executable test programs |
| `plots/` | Python script that makes the report's figures from the CSV data |
| `data/` | Experimental reference data (Martin & Moyce); `sph_experiments` writes its CSVs here too |
